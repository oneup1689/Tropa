# Tropa: журнал решений (дата, что решили, почему)

- **2026-10-14. Фильтр «скачок скорости» опирается на доплеровскую скорость GPS.** В режиме «Пешком» (10 м/с) точки в такси выбрасывались каскадом, потому что каждая сравнивалась с последней сохранённой. Доплер не зависит от шума позиции.
- **2026-10-14. Режим «Пешком» тоже режется по скорости на участки (пешком/транспорт).** Выбранный режим остаётся подписью и профилем фильтров, а способ движения определяется после записи; подсказка «Похоже, вы едете» переключает на «Смешанный», чтобы пешая часть не потерялась.
- **2026-10-14. Тишина GPS в здании с тем же местом до и после — «в помещении», а не разрыв.** Не склеивается линией, не входит во «время в движении».
- **2026-10-14. Лог отладки: один файл ≤4 МБ, отрезаются старые строки; обычные `[FIX] stored` — через одну десятую.** Объём предсказуем, причины обрывов (SKIPPED, SIGNAL, WATCHDOG, START/STOP) остаются полностью.
- **2026-10-14. Окраска линии постера: Один цвет / Скорость / Высота / Уклон; транспорт — пунктиром поверх любой.** Шкала скорости по перцентилям 10–90 % отдельно для пеших и транспортных участков, минимальная ширина диапазона 1,5 и 6 м/с. «По режиму» убрана: способ движения — структура, а не градиент.
- **2026-10-14. Нижнее меню: Тропы / Карта / Настройки; «Тропы» = «Пройденные | Маршруты».** Маршруты (импорт GPX, сохранённые прогулки) нужны для навигации и постеров не имеют; постер только из пройденного.
- **2026-10-14. Автозапись 24/7 и планировщик — один экран «Автозапись».** Это два способа «писать без кнопки»: по движению и по времени; индикатор «24/7» на карточке записи, чтобы постоянный режим был виден.
- **2026-10-14. Навигатор (v27): системный синтез речи, скачиваемые голоса не делаем.** Размер приложения почти не растёт; лицензии голосов не проверены.
- **2026-10-14. Звуки — синтез скриптом, фирменный мотив из логотипа.** Без скачивания и вопросов лицензий; отдельные каналы уведомлений под события; варианты на прослушивание владельцу.
- **2026-10-14. Поделиться картой: снимок пустой карты + маршрут рисуется кодом.** `takeSnapshot` зависает на стиле со слоями маршрута (проверено на Xiaomi 12X); как и для постеров, слои рисуются поверх снимка в Dart.
- **2026-10-15. Демо-постеры для презентации делаем на хосте, без эмулятора.** Карта-подложка рисуется собственным рендером из .pmtiles (в стиле приложения), маршруты прокладываются по реальным дорогам и рекам OSM, постер рисует код приложения. Так быстрее и воспроизводимее, чем гонять маршруты через эмулятор; на реальной карте Android-снимок MapLibre нужен только в самом приложении.
- **2026-10-15. Презентация: 8 слайдов, только слайды, видео пока нет.** Постеров не больше двух слайдов (три в ряд + «Профи-карта и неделя»), остальные слайды с экранами приложения; телефоны по пропорциям iPhone Pro. Личные фото, скриншоты и постеры хранятся только в приватном `tropa-testdata`, в публичном репозитории только исходники слайдов и скрипты.
- **2026-10-15. Тексты презентации.** Без упоминания экономии заряда в автозаписи, без «друзей» и «сторис/рилс» (подразумеваются, но не называются), лозунг «Путешествуй, сохраняй, делись!» только в финале, на обложке позиционирование «Трекер маршрутов, который работает без интернета».
