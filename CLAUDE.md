## 3. Архитектура
**Android, нативная часть (Kotlin)** — единственный пишет точки в SQLite (`tropa.db`):
- `TrackingService.kt` — foreground-сервис, состояния IDLE / WATCH / PROBE / RECORD. Запись GPS (LocationManager, GPS-провайдер), фильтры по режиму (скачки, точность, первая точка после потери сигнала), «телепорт» не добавляет дистанцию, автопауза (минуту на месте → опрос раз в 10 с), барометр (`points.pressure`), разбиение по полуночи, автозапись 24/7 (шаги ≥20 за 30 с → пробный GPS → смещение ≥30 м → сессия; конец после N мин без движения), навигация по маршруту (`route_points`, расстояние до отрезка, порог max(40 м, 2×accuracy), 3 фикса/15 с, возврат <25 м), тревоги (GPS выключен с задержкой 10 с, перезапуск системой). START_STICKY, при перезапуске продолжает ту же сессию.
- `PlannerReceiver.kt` — будильники планировщика (напоминание + автостарт), `BootReceiver.kt` — восстановление после перезагрузки, `MainActivity.kt` — канал `tropa/system` (статус сервиса, старт/стоп, watch/unwatch, планировщик, режимы Android).
**Dart:** `recorder.dart` (фасад, опрос статуса раз в секунду; на iOS запись пока в Dart через geolocator), `db.dart` (sqflite v3: sessions/points/notes/routes/route_points; Dart читает, Kotlin пишет точки), `heal.dart` (склейка разрывов, кривая Эрмита по направлению движения), `stats.dart`, `altitude.dart`+`geoid.dart` (барометр + поправка EGM96; сырая GPS-высота — эллипсоидная, во Вьетнаме ≈ −25 м), `modes.dart`, `settings.dart`/`settings_page.dart` (реестр настроек, режимы Любитель/Профи: значения хранятся всегда, режим только прячет экраны), `notes.dart` (заметки; фото/видео сохраняются в галерею через `gal`, в БД только имя), `routes.dart`/`routes_page.dart` (импорт GPX), `backup.dart` (zip: data.json + GPX, восстановление без дублей), `maps.dart`/`map_page.dart`/`maps_page.dart` (MapLibre + .pmtiles), `planner_page.dart`, `share_image.dart`/`share_dialog.dart` (картинка 1080×1920), `trim.dart` (обрезка концов при экспорте), `gpx.dart`.
**Главные уроки по карте:**
- Всё рисуемое (трек, склейка, маршрут, заметки с подписями) — слои GeoJSON внутри стиля, который записывается в ФАЙЛ `app_flutter/map/style_active.json` и передаётся в MapLibre путём. Причина: `takeSnapshot` плагина (MapSnapshotter) перечитывает стиль по пути и не видит аннотаций. Размер «плитки мира» MapLibre — 512 px (не 256).
- Недостающие диапазоны глифов шрифтов заменяются пустыми PBF (иначе MapLibre ждёт их вечно); в `assets/map/fonts` лежат только латиница, вьетнамский, кириллица.
- Скриншот окна (PixelCopy/RepaintBoundary) карту не захватывает — не использовать.
- На эмуляторе подписи карты рисуются только с `-gpu host` (SwiftShader текст не рисует).

## 5. Согласованные решения (не пересматривать без владельца)
- Тревоги: громкие только если пользователь может исправить (GPS выключен, разрешение отозвано, службу убила система); «GPS включён, но спутников нет» — без тревоги, только индикатор «Сигнал: нет N с». В приложении висит баннер с кнопкой «Включить GPS».
- Режимы путешествий: Пешком, Велосипед, Авто, Смешанный (+ Сплав позже); влияют на фильтры, пределы склейки (пешком 150 м, вело 400 м, авто 1 км), статистику, частоту GPS. Режим 24/7 — только автоматический.
- Склейка: исходные точки не меняются; в приложении цвет tertiary темы (решение владельца), в шаринге цвет маршрута (чекбокс). Длинные разрывы не склеиваются прямой линией (пунктир/тонкая линия), позже — по тропам.
- Режим Любитель (по умолчанию: тема, 24/7) / Профи (точность, интервал GPS, автопауза, склейка, обрезка начала/конца для приватности, чувствительность «сошли с маршрута», способ разбиения по дням: по паузе (по умолчанию) или по полуночи).
- Режим 24/7 включается в настройках, по умолчанию выключен; запись стартует сама и заканчивается после 5 мин без движения.
- Зона приватности при шаринге отдельно не делаем (есть обрезка концов в Профи).
- Медиа заметок хранятся в галерее телефона (альбом Tropa), а не в приложении.
- iOS — отдельным этапом после Android.
